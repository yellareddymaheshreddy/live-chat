
# LiveChat — Real‑Time Messaging System

This repository contains a **full real‑time chat platform**, built from scratch using:

- ⚡ **Bun** WebSocket backend
- 🌐 **Next.js** frontend
- 🔥 Live typing indicators
- 🏠 Multi‑room chat support
- 🧠 Clean, extensible architecture

### 📂 Project Structure

```
livechat/
 ├─ fe/   # Next.js Frontend
 ├─ be/   # Bun WebSocket Backend
 └─ README.md (this file)
```

### 🚀 Goal

Build a fast, modern real‑time messaging system — no Firebase, no Socket.io, just **raw WebSockets** and performance‑focused code.
